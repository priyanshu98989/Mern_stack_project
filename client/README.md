# CertTrack client

React + Vite single-page application for CertTrack.

## Development

From this directory:

```bash
npm install
npm run dev
```

The app expects the API at `http://localhost:5000`. Override it with
`VITE_API_URL` in `client/.env`.

## Scripts

| Command           | Purpose                       |
| ----------------- | ----------------------------- |
| `npm run dev`     | Start the Vite dev server     |
| `npm run build`   | Production build into `dist/` |
| `npm run preview` | Preview the production build  |
| `npm run lint`    | Run Oxlint                    |

See the root [README](../README.md) for the full project documentation.
